HOW TO READ THIS
------------------------------------------------------------------------------
  A deviation is only meaningful when the engine output and the source value are
  the SAME economic or environmental endpoint AND are expressed in the SAME
  currency and price year. Rows marked 'endpoint mismatch' are not compared.
  Rows marked 'range' are plausibility checks against a published envelope, not
  point predictions, and are never converted to a percentage deviation from an
  envelope midpoint. Rows marked 'NOT COMPARABLE' carry no percentage at all.

  AlgaMetrix has no currency of its own: it returns a cost in the units of the
  price set it was fed. Each row therefore states the basis of the engine value,
  the basis of the source value, and any transformation between them. Where a
  scenario mixes source prices with shipped library defaults, it is run a second
  time with those defaults expressed in the source's currency and the deviation
  is given as the interval the two readings span.
