THE VERIFICATION SUITE (SI TABLE S-B)
==============================================================================
the 27 structurally distinct scenarios the verification and consistency checks run over
generated by reproduce.py on 2026-10-26

  Origin: a reconstruction is a published case rebuilt from its source, a
  template a configuration shipped with the software, an archetype one of the
  sensitivity and uncertainty archetypes, and a variant a shipped
  configuration changed to reach a code path the others do not. The set was
  put together to cover the configuration options of the model, not to sample
  the industry; the counts at the end say how often each option is exercised.
  Members that build an identical scenario by another route are listed under
  'also built as' and counted once.
